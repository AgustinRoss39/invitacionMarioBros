# Invitación Mario Bros — Ross Digital Studio

Versión modernizada y reorganizada de la invitación temática Mario Bros.

## Estructura

- `index.html`: estructura principal de la invitación
- `css/styles.css`: estilos responsive y estética de la temática
- `js/config.js`: datos editables de cada evento y personajes utilizados
- `js/app.js`: lógica reutilizable (contador, música, animaciones, WhatsApp y enlaces)
- `assets/img`: imágenes de la temática
- `assets/audio`: música

## Personalización rápida

Para crear una nueva versión de esta invitación, la mayoría de los datos se modifican únicamente en `js/config.js`:

- nombre y edad
- mensaje principal
- fecha y horario
- lugar y dirección
- enlace de Google Maps
- WhatsApp y mensaje de confirmación
- Instagram de Ross Digital Studio
- personajes que rotan en la portada

La lógica general permanece en `js/app.js`, por lo que no hace falta tocarla para personalizaciones normales.

## Estándar Ross Digital Studio

Esta estructura será la base para modernizar el resto de las invitaciones: mismo funcionamiento general, pero conservando una identidad visual propia para cada temática.
