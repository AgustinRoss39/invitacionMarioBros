# Invitación Mario Bros — Ross Digital Studio

Versión modernizada y reorganizada de la invitación temática Mario Bros.

## Estructura

- `index.html`: estructura principal
- `css/styles.css`: estilos responsive
- `js/app.js`: configuración y comportamiento
- `assets/img`: imágenes de la temática
- `assets/audio`: música
- `assets/fonts`: tipografías locales

## Personalización rápida

Los datos principales de la invitación se editan desde el objeto `invitation` en `js/app.js`: nombre, edad, fecha, horario, lugar, dirección, Google Maps, WhatsApp e Instagram.
